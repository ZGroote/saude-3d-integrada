# Saúde 3D Integrada

Prontuário 3D multidisciplinar e longitudinal, da gestação à vida adulta.

- `Saude-3D-Integrada-Conceito.pdf`: documento de conceito.
- `SPEC-MVP.md`: especificação técnica do MVP.
- `teste-anatomia/`: teste de geração das camadas anatômicas a partir de tomografia (veja o `LEIAME.md` de lá).

Os modelos em `teste-anatomia/modelos` derivam do TotalSegmentator Dataset (CC BY 4.0); crédito completo em `teste-anatomia/LEIAME.md`.
